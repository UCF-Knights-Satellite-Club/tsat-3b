# Main board

The TSat-3B flight computer: ESP32-WROOM, BNO085 IMU, SAM-M8Q GPS, BMP581 barometer, RFM95 LoRa radio, and the servo bus.
Designer: Pablo J.

**Not uploaded yet.** The design lives on Discord for now. Upload the whole KiCad project here (`.kicad_pro`, `.kicad_sch`,
`.kicad_pcb`, any custom libraries) together with a schematic PDF and, once it's ready to order, Gerbers in `fabrication/`. Use the
same layout as [`../PowerDistributionBoard/1.5U-Rev1/`](../PowerDistributionBoard/1.5U-Rev1/).
